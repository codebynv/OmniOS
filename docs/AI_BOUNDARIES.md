# AI Boundaries

OmniOS should use AI where it adds operational value without making critical system behavior opaque.

## Appropriate AI tasks

- Summarization
- Classification
- Information extraction
- Natural-language search
- Assisted recommendations

## Deterministic tasks

Keep authentication, authorization, financial calculations, validation, persistence, and irreversible actions deterministic and auditable.

## Rule

AI may assist a business workflow, but the application should retain explicit validation and control over the resulting action.
