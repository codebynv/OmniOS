# AI Evaluation Cases

Keep a small regression set for AI-assisted workflows.

- A normal, well-formed request.
- Missing required information.
- Malformed or unexpected tool output.
- Untrusted instructions embedded in retrieved content.
- A provider timeout or unavailable dependency.
- A request the current user is not authorized to perform.

Record expected behavior and review changes against the same cases. Do not claim an evaluation passed unless it was run.
