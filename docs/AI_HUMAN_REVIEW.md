# AI Human Review

Define which AI-assisted outcomes require human review before execution.

Review is especially important for actions that are external, irreversible, financially consequential, or affect sensitive business records.

- Show the proposed action and relevant context.
- Validate permissions independently.
- Allow rejection or correction.
- Record the final outcome where appropriate.
- Provide a safe path when the model is uncertain.

Model confidence alone should not authorize a consequential action.
